# 江湖 Slay（文字版英雄杀）

1v1 回合制卡牌对战。选择历史英雄，与 AI 或好友对战，通过出牌与技能击败对手。

## 运行

需要 Python 3.9+。

推荐用法说明也写在博客页：[江湖 Slay 玩法说明](https://wq-win.github.io/game/jianghu-slay.html)。

### 一键启动（推荐）

```bash
./scripts/start.sh        # 本机人机对战（默认）
./scripts/start.sh host   # 本机当服务器，开房给好友
```

首次运行会自动创建 `.venv` 并安装依赖。

| 模式 | 谁能访问 | 适合 |
|------|----------|------|
| `ai`（默认） | 仅本机 `http://127.0.0.1:8000` | 平时自己打 AI |
| `host` | 本机 + 局域网；可再配 ngrok | 偶尔双人房间对战 |

**双人流程（host）：** 房主创建房间 → 把地址和房间码发给对方 → 对方用同一地址打开并加入（不要再开自己的服务）→ 双方选英雄并准备开战。跨网时房主另开终端执行 `ngrok http 8000`，把 https 链接发给对方。

### 终端版

```bash
python main.py
```

### 网页版（手动）

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=. uvicorn server.main:app --host 127.0.0.1 --port 8000   # 本机 AI
# 开房改为 --host 0.0.0.0 --port 8000
```

浏览器打开 <http://127.0.0.1:8000> 。

- **人机对战**：选英雄后开局
- **创建房间 / 加入房间**：双方选英雄并「准备开战」后开始；刷新页面会按本地令牌尝试重连

也可用 Docker：

```bash
docker build -t jianghu-slay .
docker run -p 8000:8000 jianghu-slay
```

## 玩法简介

- 每轮依次进行你的回合与 AI 回合。
- 回合流程：摸牌 → 出牌阶段 → 弃牌至手牌上限（等于当前血量，部分英雄有加成）。
- 输入手牌编号出牌，输入 `0` 结束出牌阶段。
- 手牌用尽时自动结束出牌阶段。
- 目标：将对手血量降至 0。

### 常用操作

| 输入 | 说明 |
|------|------|
| `1`、`2`… | 打出对应编号的手牌 |
| `0` | 结束出牌阶段 |
| `q` / `w` / `e` / `r` | 发动主动技能（见下方英雄说明，可附带手牌编号） |
| `sha 1 2` | 装备丈八蛇矛后，将两张手牌当杀使用 |

### 主动技能示例

| 英雄 | 命令示例 |
|------|----------|
| 刘邦（驭人） | `q 1 3` — 弃第 1、3 张牌并摸等量牌，每回合一次 |
| 赵匡胤（释权） | `q 2` — 将第 2 张黑色手牌当釜底抽薪 |
| 杨再兴（冲阵） | `q 1` — 将第 1 张闪当杀 |
| 项羽（霸王） | `q` — 失去 1 点血并摸 1 张牌，可多次发动，杀伤害叠加 |
| 褒姒（换牌） | `q all` — 交换全部手牌；`q 1 2` — 用第 1、2 张与对手 2 张交换，每回合一次 |

## 牌型

**基本牌**：杀、血杀、毒杀、闪、桃、酒（濒死时可当桃使用）

- **杀**：普通攻击
- **血杀**：命中后，攻击者回复与伤害等量的血量
- **毒杀**：命中后，目标下回合开始前判定，若为黑色则不能摸牌

每张牌随机分配花色（红桃/方块/黑桃/梅花）与点数（1–10、J、Q、K），显示如 `[梅花K]血杀`；红桃、方块为红色，黑桃、梅花为黑色。

**锦囊**：无中生有、顺手牵羊、釜底抽薪、决斗、烽火狼烟、万箭齐发、手捧雷、画地为牢

- **手捧雷**：目标下回合开始前判定，非红桃受 3 点伤害，红桃则传给对手
- **画地为牢**：目标下回合不能使用杀

**装备**：武器、防具、进攻马（-1 马）、防御马（+1 马）

## 项目结构

```
JianghuSlay/
├── main.py              # 终端入口
├── game.py              # 游戏引擎（回合、战斗、出牌）
├── heroes.py            # 英雄数据
├── models/              # 数据模型（牌、玩家、牌库）
├── skills/              # 技能钩子与主动技
├── cards/               # 锦囊效果注册
├── ai/                  # AI 策略
├── engine/              # UI 协议（Event / Prompt / View / StateDTO）
├── ui/                  # 终端 Adapter
├── server/              # FastAPI + WebSocket
└── web/                 # React 卡牌客户端（public 为可直接托管静态资源）
```

## 扩展指南

### 添加被动技能

1. 在 `skills/passive.py` 编写 handler 函数
2. 在 `HERO_SKILL_HOOKS` 中注册对应英雄

可用钩子包括：`on_turn_start`、`on_turn_end`、`on_damaged`、`on_dodge`、`sha_damage_bonus`、`tao_heal_bonus`、`hand_limit_bonus` 等。

### 添加主动技能

1. 在 `skills/active.py` 编写 `player` 与 `ai` handler
2. 在 `ACTIVE_SKILLS_BY_HERO` 中注册

### 添加锦囊

1. 在 `cards/scrolls.py` 编写效果函数
2. 注册到 `SCROLL_REGISTRY`（有使用条件则加入 `SCROLL_PLAY_CHECKS`）
3. 在 `models/deck.py` 的牌库配置中加入该牌

### 添加英雄

1. 在 `heroes.py` 的 `HEROES` 列表中添加
2. 在 `skills/` 中注册其技能
